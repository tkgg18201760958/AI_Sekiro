设计以下模块：

## 1. 游戏状态读取模块 State Reader

功能：

负责获取只狼当前状态。

初期假设通过读取游戏内存获取：

包括：

- 玩家HP
- 玩家架势值
- Boss HP
- Boss架势值
- 玩家位置
- Boss位置
- 距离
- Boss当前动作状态
- 玩家是否受击
- 是否可以执行弹刀


输出统一格式：

例如：

{
player_hp:0.8,
player_posture:0.5,
boss_hp:0.6,
boss_posture:0.7,
distance:3.2,
boss_action:"attack"
}


要求：

必须可以单独测试：

运行：

python test_state_reader.py

可以实时显示：

当前读取的数据。

在没有真实读取成功时，需要提供模拟数据模式。
